# RQF-SAMCHAT-ASSISTANT-052R - Specialist Case Memory Grounding Spec

Status: IMPLEMENTED_LOCAL

## Boundary

Specialist case memory grounding is a read-only enrichment layer for the assistant preview surface.

It may read:

- current conversation scope;
- user message terms;
- persisted `AssistantArtifact` rows with `artifact_type = case_memory_summary`;
- artifact metadata already generated by deterministic case memory.

It must not:

- call an external provider;
- create, update or delete records;
- infer authority from precedent;
- expose memory from another employee's conversations;
- mark a preview executable.

## Contract

`memory_context` shape:

```json
{
  "source": "case_memory_artifacts",
  "lookup_performed": true,
  "authority": "read_only_memory",
  "matched": true,
  "status": "matched",
  "snippets": [
    {
      "label": "memory:case_summary:<artifact-id>",
      "score": 1.23,
      "conversation_id": "<uuid>",
      "artifact_id": "<uuid>",
      "module_key": "expenses",
      "tournament_key": "copa_telmex",
      "text": "Memoria de caso resumida :: ..."
    }
  ],
  "limits": {"top_k": 3}
}
```

Fail-closed statuses:

- `skipped_no_db_session`
- `skipped_no_employee_scope`
- `skipped_no_query_terms`
- `no_matches`
- `lookup_error`

## Integration points

- `conversation_service._build_specialist_preview_surface_response`
  - resolves memory context after live context;
  - renders a `Memoria de casos` section;
  - persists `memory_context` in tool payload;
  - adds it to tool trace.
- `specialist_live_context.build_specialist_preview_workspace_cards`
  - adds a `case_memory` card when memory context is provided.
- `assistant_workspace_trace.build_specialist_workspace_step_trace`
  - adds a read-only memory step.
- `assistant_workspace_trace.build_specialist_workspace_source_panel`
  - adds a `case_memory_readonly` source.

## Verification

Focused tests must cover:

- deterministic rendering of memory snippets;
- card/source/step exposure;
- conversation response payload includes memory context;
- memory does not unlock writes.
